# 🚀 Fixora

Fixora is a modern home-service booking platform designed to make it easy for users to discover, book, pay for, and track service professionals.

## ✨ Features

- 🔐 User Sign Up
- 🔑 User Login
- 👤 User Account
- 🛠️ Home Service Booking
- 📅 Date & Time Selection
- 👨‍🔧 Professional Selection
- 📍 Service Address
- 📝 Problem Description
- 💳 Online Payment UI
- 🧾 Booking Invoice
- 🆔 Unique Booking ID
- 💰 Transaction ID
- 🚗 Service Tracking
- ❌ Booking Cancellation
- 📋 My Bookings
- 📱 Responsive Design
- 🌌 Modern Animated UI
- 🔔 Toast Notifications
- 🔒 Local User Session
- 💾 Browser LocalStorage

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage API
- Responsive Web Design
